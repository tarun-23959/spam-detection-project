# Spam Detection Project

A Machine Learning based Spam Detection System developed using Python.

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-Learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes
- SMOTE
- Tkinter

## Features
- Single Message Spam Detection
- Bulk Message Spam Detection
- Text Preprocessing
- Stopword Removal
- Stemming
- GUI-based Application

## Dataset
spam_ham.txt
